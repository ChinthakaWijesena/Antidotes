Everything your PC needs, in one app.

Ten tools that replace a folder full of separate utilities. Built with Flutter and native Win32 APIs, so it stays fast.

Junk Cleaner

Scans only safe, whitelisted locations in background Isolates with zero UI freeze, flags risky files, and skips anything changed in the last 24 hours.

Startup Optimizer

See which apps launch with Windows, check how much they slow boot, and switch them off.

Browser Cleaner

Clear caches, cookies and session leftovers in Chrome, Edge, Firefox, Opera, Opera GX, Brave and IE without slowing down your system.

RAM Optimizer

Trim process memory, clear the system cache and purge the standby list to free RAM on demand.

Hardware Monitor

Live CPU, RAM, GPU, temperature and fan readings in one place.

Disk Health

S.M.A.R.T. status, temperature and lifespan checks, so you know a drive is failing before it does.

Software Manager

Install apps silently with winget, and uninstall programs cleanly.

DNS Changer and Speed Test

Switch DNS in one click with Family Shield mode, automatic 10s live latency checks with Low-to-High sorting, and real bandwidth benchmarking.

Storage Tools

Find large files and duplicates, and shred sensitive files for good with DoD or Gutmann methods.

Windows & App Settings

Sync system theme, tune power plans, virtual memory and environment variables, plus dedicated App Settings with built-in In-App Auto-Updater.

Build it yourself

You need the Flutter SDK (3.13.5 or newer), Visual Studio 2022 with Desktop development with C++, and Inno Setup 7 for the installer.

PowerShell
flutter pub get
flutter analyze --no-fatal-infos
flutter test --no-pub
flutter build windows --release
& "C:\Program Files\Inno Setup 7\ISCC.exe" installer\antidotes_setup.iss
